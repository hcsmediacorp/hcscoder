# Security policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch (`v1.x` / current semver).

## Reporting a vulnerability

Please report security issues **privately** to **hcsmediagroup@gmail.com** (include steps to reproduce and impact). Do not open a public GitHub issue for undisclosed vulnerabilities.

We aim to acknowledge reports within a few business days.

## Scope

- **hcscoder** CLI and library code in this repository.
- Out-of-scope: third-party services (e.g. OpenRouter) — report provider issues to the respective vendor.
